# MESOB TO DO

MESOB TO DO is a modern task management mobile application built with **Flutter** and powered by a **Node.js backend API**. The application allows users to efficiently manage their daily tasks by creating, updating, and organizing todos in a clean and user-friendly interface.

The goal of the application is to help users stay productive and organized by providing a simple and reliable platform for task tracking. Users can register, log in securely, manage their personal task lists, and update their account information directly from the app.

The frontend of the application is developed using **Flutter**, providing a smooth and responsive mobile experience, while the backend is implemented with **Node.js** and deployed online to handle authentication, data storage, and API communication.

## Installation
Follow the steps below to run the project locally.

### 1. Clone the repository
git clone https://github.com/MUGERWAIBRAHIM/MESOB_TO_DO.git

### 2. Navigate to the project directory
cd MESOB_TO_DO/todo_frontend

### 3. Install dependencies
flutter pub get

### 4. Run the application
flutter run
Note: Make sure you have an Android emulator running or a physical device connected.

## Requirements
* Flutter SDK installed
* Android Studio or VS Code
* An Android emulator or physical device
* Internet connection (to communicate with the backend API)
